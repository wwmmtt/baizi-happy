# 六书定位、主题路由与语料库

## 各书定位（决定先查哪本）

| 书 | 入库情况 | 擅长 | 在库标记 |
|---|---|---|---|
| 三命通会 | 476 块（卷—门—条完整） | 神煞、六亲、女命、纳音、官杀格局、刑冲 | `三命通会` |
| 滴天髓 | 257 块（通神论/六亲论/形象论等） | 旺衰、气势、寒暖燥湿、病药、用神喜忌 | `滴天髓` |
| 子平真诠 | 69 块（原序 + 一～四十余篇全） | **格局成败、用神变化、相神救应**——格局第一顺位 | `子平真诠` |
| 穷通宝鉴 | 143 块（十干×十二月逐条切片） | **调候**（某日主生某月用什么）——最硬的“按月取用” | `穷通宝鉴` |
| 渊海子平 | 131 块（164 页 PDF，按《论X》分节） | 十神基础、正官/七杀/财/印各论、太岁、性情、疾病、诗诀 | `渊海子平` |
| 命理正宗 | 18 块（手抄本，约 1.7 万字） | **金不换断**（甲日子提…这类按月直断的口诀）、六亲断语 | `命理正宗` |

两处短板必须在解释时说清：

- **《命理正宗》是手抄本**（金不换断、六亲赋这类口诀体），**不是《神峰通考》的理论全本**。问“病药”（张神峰那套“病在哪、药是什么”）它给不出系统论述——用 `--topic 病药` 会基本落到《滴天髓》。问“某日某月吉凶”它最有用。
- **《渊海子平》按《论X》篇目分节**，篇目全但每篇文气被 PDF 折行，读引文时留意断句。

**金不换断的正确问法**：用户问“甲日生十一月怎样”时，检索词用日主+月支（如 `甲木 子月`，检索器会自动展开成“甲日/子提/十一月”），再用 `--book 命理正宗` 限定，读整块（一块里有多条断语，自己挑对应那条）。

## 主题路由 → 书目裁断顺序

先判“事”落在哪个主题，再按该主题的顺序查（左优先，右补证）：

| 主题 | 裁断顺序（先→后） | 什么时候用 |
|---|---|---|
| 格局 | 子平真诠 → 三命通会 → 渊海子平 → 命理正宗 | 官格/杀格/财格/印格/食伤格成败、成格破格、相神救应 |
| 调候 | 穷通宝鉴 → 三命通会 → 滴天髓 | “我这个日主生在这个月，该用什么”——最实用的一环 |
| 旺衰 | 滴天髓 → 子平真诠 → 渊海子平 | 身强身弱、通根得令、能不能担财官 |
| 神煞 | 三命通会 → 渊海子平 | 桃花、羊刃、贵人、驿马、魁罡、空亡 |
| 六亲 | 三命通会 → 渊海子平 | 父母、兄弟、妻、子女 |
| 女命 | 三命通会 → 渊海子平 | 旺夫克夫、再嫁、贞洁 |
| 纳音 | 三命通会 → 渊海子平 | 纳音五行、六十甲子 |
| 基础 | 渊海子平 → 三命通会 | 干支、五行生克、刑冲合会、藏干 |
| 流年 | 三命通会 → 滴天髓 | 太岁、岁运并临、天克地冲 |
| 病药 | 滴天髓 → 命理正宗 | 命局的“病”在哪、“药”是什么（命理正宗只有口诀，主看滴天髓·疾病章） |
| 直断吉凶（某日某月） | 命理正宗·金不换断 → 穷通宝鉴 | 用户要“一句断语”时，先拿金不换的按月口诀，再看穷通宝鉴的取用 |

裁断顺序只是排序参考，不是“谁对”。它解决的是“同一问题六本书都有话说时，先听谁”，不解决“谁说得对”。用户追问“到底哪个准”时，直接答：命理本身无客观真值，本技能只保证忠于原文、可溯源。

## 数据源

- **随包语料**：`data/chunks_all.jsonl`（1094 块，UTF-8 JSONL，一行一块，约 1.5MB）。脚本按相对路径自动读取，无需手工指定，换电脑也能用。
  字段：`book` 书名 / `juan` 卷 / `men` 门或篇 / `tiao` 条号 / `tags` 十神神煞标签 / `topics` 主题标签 / `text` 正文 / `prio` 书目全局优先级。
  各书块数：三命通会 476、滴天髓 257、穷通宝鉴 143、渊海子平 131、子平真诠 69、命理正宗 18。
  主题分布：调候 174、六亲 99、基础 95、格局 64、神煞 52、旺衰 47、女命 14、流年 11。
- 发布版只保留检索与排盘所需文件；原始 PDF、单书库、向量模型、语料重建脚本均未随包分发。
