# 解读细则与标准动作

## 只报凶、不给路 = 没答完整

古书只**诊断吉凶**，不给“怎么改”——这是命理的老毛病，技能必须补上缺的那一半：

- 每次解读末尾必须给「现实行动建议」，不许把“不好”扔给用户就完事。
- 行动建议基于现实（法律、财务、健康、关系、作息），可操作，大白话。
- 明确标注「这是现实建议，不是命理」。
- 绝不编造迷信化解：不写“佩戴某物、改名、做法事、花钱消灾”。
- 举例：“孩子缘薄”→ 探视权走法律、多陪伴、别松劲；“财弱”→ 稳收入、别乱投；“这段运感情要小心”→ 别急着定、看清人。

## 引文与出处

- 输出顺序：一句白话结论 → 命盘依据 → 原文出处 → 现实行动建议；需要时再附排盘全表（四柱 / 十神 / 纳音 / 大运 / 流年 / 神煞）。
- 原文出处逐条标“《书名》·卷X·门X”。示例：《三命通会》·卷五·论正官；《滴天髓》·十五、月令；《穷通宝鉴》·论丙火。
- **没查到的书不许出现在出处里。** 查不到就答“库中未检索到相关内容”，并说明是哪本缺。
- 《命理正宗》只有手抄口诀体、理论篇章缺；《渊海子平》每篇被折行。要在必要时向用户说明这些限制。

## 附录：格式与扫描件处理

- 直接检索：`.txt` `.md` `.json` `.csv` 等 UTF-8 文本。
- `.epub` 是 zip，解压后处理里面的 `.html/.xhtml`，忽略标签只看正文。
- `.pdf`：有文字层可直接 `pymupdf` 抽文（本库六书现在都有文字层）；**无文字层（竖排木刻扫描）**才需要逐页渲染成图再视觉转录（RapidOCR 对此类竖排双栏扫描基本失效，实测只能识出两三个字）。以后若换回扫描版，先确认有没有文字层再决定要不要 OCR。

## 附录：一次完整问事的标准动作

用户问“我这命走这条运能不能成事”时，固定四步：

1. `pai_pan.py` 出 JSON，只读命盘字段（四柱、十神、藏干、大运、流年），不许自己改干支。
2. 定主题：问事业 → `--topic 格局`；问“该补什么/适合什么行业” → `--topic 调候`；问“担不担得住财” → `--topic 旺衰`；问婚姻子女 → `--topic 六亲`。
3. 检索 2 轮：第一轮按裁断顺序取正说；第二轮对冲突点用 `--flat` 或 `--book` 摊开异说。
4. 输出：一句话结论 → 命盘事实 → 原文（标书名卷门）→ 现实行动建议。缺书、缺信息、查不到，都要明说。
